## 📌 Project Overview

This project focuses on understanding the fundamentals of password cracking and password security through an authorized cybersecurity lab provided by NetworkWalks.

The objective of the lab is to recover the password of a protected PDF file by first extracting its password hash and then using the NetworkWalks Password Cracker to identify the original password.

This practical exercise demonstrates how weak passwords can be recovered from protected files and highlights the importance of using strong and secure passwords.

## 🧠 Key Concepts Learned

### Password Cracking

Password cracking is the process of recovering a password from stored or protected data.

Security professionals can use password-cracking techniques in authorized environments to evaluate password strength and demonstrate the risks associated with weak passwords.

### Hashing

A hash is a scrambled representation of data.

In this lab, the password associated with the protected PDF was represented through a hash, which was extracted and then provided to the password-cracking tool.

### Encryption vs Hashing

Encryption is a two-way process where encrypted information can be decrypted using the appropriate key.

Hashing is generally treated as a one-way process that converts input data into a message digest.

---

## 🔐 Security Importance

This exercise demonstrates why strong passwords are important.

Passwords that are short, common, or easy to guess can potentially be recovered more quickly through password-cracking techniques.

Strong passwords should therefore use sufficient length and complexity and should avoid commonly used or predictable patterns.
